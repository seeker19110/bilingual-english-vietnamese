# Spec: V2-15 Work Domain

**Trạng thái:** Approved for implementation
**Ngày:** 2026-08-17
**Tác giả:** Antigravity AI
**Mục tiêu:** Xây dựng Bounded Context Work Domain cho Personal OS theo 21-ROADMAP.md Wave E.

## 1. Bối cảnh & Mục tiêu

- Cung cấp các primitives quản lý công việc chuyên nghiệp: Projects, Tasks, Meetings, Documents và Deadlines.
- Giữ vững nguyên tắc confirmation boundary: các hành động ghi hoặc tích hợp ra ngoài đều phải qua ProposedAction và cơ chế kiểm soát quyền hạn.

## 2. Thiết kế kỹ thuật

- **Database (`postgres/migrations/0048_work_domain.sql`)**: Schema `work` gồm các bảng:
  - `work.projects`: id, person_id, name, description, status, deadline, version, timestamps.
  - `work.tasks`: id, person_id, project_id, title, priority, status, due_at, version, timestamps.
  - `work.meetings`: id, person_id, title, scheduled_at, duration_minutes, summary, action_items, timestamps.
  - `work.documents`: id, person_id, project_id, title, document_type, summary, content_uri, version, timestamps.
- **Contracts (`packages/core-contracts/work.ts`)**:
  - Schemas `WorkProjectSchema`, `WorkTaskSchema`, `WorkMeetingSchema`, `WorkDocumentSchema`.
- **Service (`packages/core-work/workService.ts`)**:
  - Quản lý lifecycle của Projects, Tasks (với optimistic locking qua `version`), Meetings và Documents.
- **API (`api/work.ts`)**:
  - GET `/api/work`: `?kind=projects`, `?kind=tasks`, `?kind=meetings`, `?kind=documents`.
  - POST `/api/work`: Tạo mới project, task, meeting, document.
  - PATCH `/api/work`: Cập nhật project, task.
  - Auth-guarded, rate-limited, CORS/Security headers đầy đủ.
