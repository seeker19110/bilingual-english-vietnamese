## 0. Một câu

Làm dày **chặng S3 (nâng cao)** của cả 13 hướng chuyên sâu từ mức *bản đồ* (module + dự án) lên
mức **thi hành và nghiệm thu được**: điều kiện vào, bài luyện + bằng chứng cho từng module, thang
chấm dự án có SỐ, bẫy riêng của chặng, dấu hiệu qua chặng — kèm test canh gác và giao diện.

**Vì sao chọn S3 (không phải S1/S2/S4):** S1–S2 là kiến thức có sẵn ở mọi giáo trình; S4 phụ
thuộc bối cảnh công ty nên không đặc tả chung được. S3 đúng là chỗ người học **khựng lại**: biết
làm cho chạy rồi, nhưng không biết thế nào là "đủ tốt" — mà "đủ tốt" thì đo được, nên đặc tả
được.

**LÀM:**

  `exitSignals` · `nextStagePrep`.
- Sổ đăng ký + hàm tra cứu (`getStageDetail`, `countStageDetails`, `countDrills`).
- **Test bất biến canh gác khuôn** (`stageDetails.test.ts`) — xem ô ⑤.
- Giao diện: khối "Chi tiết chặng 3" **trong thẻ chặng S3** ở trang
  `/lap-trinh/huong/:specId` (không thêm route mới).
- Sửa luôn chữ sai đang có trên trang: nút "Xem **12** hướng chuyên sâu" → 13.

**KHÔNG LÀM (quan trọng ngang mục trên):**

- **Không** soạn bài học 8 bước / không đụng `lessons*.ts`, `projectSteps*.ts` — tầng này là
  *bản đồ chi tiết*, không phải nội dung chạy code. (Việc để ngỏ số 1 của changelog 0175.)
- **Không** lưu tiến độ xuống Postgres, không thêm migration, không thêm API. (Để ngỏ số 2.)

- **Không** sửa dữ liệu S1/S2/S4 đang có, **không** đổi `types.ts` cũ, **không** đổi id chặng /

## ③ Hợp đồng dữ liệu

**Vào:** không có I/O — dữ liệu là hằng biên dịch, tất định (cùng luật với `specializations/`).

**Ra:**

```ts
/** Bài luyện của MỘT module trong chặng — gắn với module có thật qua `moduleId`. */
export interface SpecModuleDrill {
  /** Phải khớp đúng một `SpecModule.id` của chặng S3, ví dụ 'web-s3-m1'. */
  moduleId: string
  /** Việc phải LÀM (một câu, động từ đứng đầu) — không phải "đọc hiểu về…". */
  drill: string
  /** Bằng chứng nộp: lệnh chạy được hoặc số đo. Bắt buộc có con số hoặc `lệnh`. */
  evidence: string
}

/** Một dòng thang chấm dự án chặng. */
export interface SpecRubricRow {
  criterion: string
  /** Ngưỡng ĐẠT — bắt buộc chứa CON SỐ. "Nhanh hơn" không phải tiêu chí. */
  pass: string
  /** Dấu hiệu CHƯA đạt, viết cụ thể để tự chấm được. */
  fail: string
}

export interface SpecStageDetail {
  /** '<hướng>-s3'. Phải trỏ tới một `SpecStage` có thật. */
  stageId: string
  /** 3–5 điều kiện vào, mỗi điều kiện tự kiểm được. */
  entryGate: string[]
  /** Phủ ĐÚNG tập module của chặng: không thiếu, không thừa, không trùng. */
  moduleDrills: SpecModuleDrill[]
  /** ≥ số `requirements` của dự án chặng. */
  projectRubric: SpecRubricRow[]
  /** 2–4 bẫy RIÊNG của chặng S3 hướng này. */
  pitfalls: string[]
  /** 3–5 dấu hiệu quan sát được là đã qua chặng. */
  exitSignals: string[]
  /** Một câu: xong S3 thì chuẩn bị gì cho S4. */
  nextStagePrep: string
}
```

**Ca lỗi (là một phần hợp đồng):**

| Tình huống                            | Hành vi mong đợi                                                          |
| ------------------------------------- | ------------------------------------------------------------------------- |
| `getStageDetail('web-s9')` — id lạ     | trả `undefined`, KHÔNG đoán bừa chặng gần đúng                            |
| Hướng chưa có chi tiết                 | `undefined` → giao diện **ẩn hẳn khối**, không hiện khối rỗng             |
| `moduleId` trỏ module không tồn tại    | **test đỏ ở CI**, không phải lỗi lúc chạy                                 |
