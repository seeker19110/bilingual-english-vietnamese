# 0203 — Chương C2–C4 khoá Hermes, đủ 4 chương/22 bài (PR 3/3 khoá Hermes)

PR cuối trong 3 của khoá "Hermes Agent — trợ lý AI cho người đi làm"
(`docs/specs/2026-08-31-khoa-dieu-phoi-ai-van-phong.md`, PR 1 #751 · PR 2 #752). Hoàn tất
đúng đề cương 2 ảnh tham chiếu Hermes Agent Course.

## Đã làm

- **15 bài mới** bám đúng 15 mục còn lại của đề cương, mỗi bài đủ 8 bước + 2–3 thẻ SRS, góc
  nhìn văn phòng/điều phối dev:
  - `lessons/hermesu2.ts` — chương **C2 Công cụ nâng cao** (5 bài): `/goal` & `/steer` (mục
    tiêu bền bỉ vs lái giữa chừng, luật một-mục-tiêu) · `/learn` (ba pha đúc kỹ năng: làm
    cùng cho đạt → nghiệm thu → đóng gói) · LiteLLM (proxy kiểm soát chi phí cả phòng,
    `hermes model litellm/…`) · llama.cpp (self-host giữ dữ liệu không rời công ty, chiến
    lược "hai đường") · Open WebUI (cửa hỏi-đáp cho người không dùng terminal, phân vai với
    Hermes CLI).
  - `lessons/hermesu3.ts` — chương **C3 Tech stack ứng dụng** (5 bài): Memos (biên bản họp
    có cấu trúc, nghiệm thu trước khi thành "sự thật chính thức") · Linear (giao việc agent
    như giao dev, kỷ luật mô tả rõ) · Bookmark (tư liệu ngoài kèm ngữ cảnh, khác Memos nội
    bộ) · Understand-anything (đọc-hiểu TRƯỚC, nghiệm thu, rồi mới hành động — 2 bước tách
    bạch) · Design & Frontend skill (landing page theo nội dung cụ thể, ranh giới việc-giao-
    được vs việc-của-người).
  - `lessons/hermesu4.ts` — chương **C4 Multi-agent và hệ sinh thái** (5 bài): Kanban (bảng
    việc chung người+agent, quét 3 cột) · Herdr (điều khiển nhiều luồng/profile song song) ·
    Firecrawl (trích xuất web, luật bắt buộc "kèm link nguồn") · Honcho (bộ nhớ dài hạn khác
    session/skill, rủi ro lỗi thời) · Paperclip (bài tổng kết — "công ty 0 người" hội tụ
    profile + skill + Kanban + việc nguyên tử + nghiệm thu người).
- `courses/hermes.ts` — mở đủ 4 chương (trước đó PR #752 chỉ có C1); `lessons.ts` nối 3
  import mới; `lessonsHermes.test.ts` cập nhật số bài kỳ vọng 7 → 22.
