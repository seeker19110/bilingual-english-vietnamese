# 0216 — 2026-09-01 — Vật lí 12 Chương 1-4 (25 bài, GĐ3 Vật lí đợt 3)

Đặc tả: `docs/goals/2026-08-31-mon-hoc-toan-ly-hoa-sinh.md` (Goal M3/S3, hoàn thành). Đối chiếu mục lục SGK "Kết nối tri thức" Vật lí 12 để đảm bảo đầy đủ bài học.

### Thay đổi

1. **Soạn đủ 25 bài Vật lí 12** phân bổ qua 4 chương:
   - `ly12c1.ts` (Chương I: Vật lí nhiệt - 7 bài)
   - `ly12c2.ts` (Chương II: Khí lí tưởng - 4 bài)
   - `ly12c3.ts` (Chương III: Từ trường - 8 bài)
   - `ly12c4.ts` (Chương IV: Vật lí hạt nhân - 6 bài)
     Tất cả bài học có cấu trúc chuẩn: Hook dẫn dắt trực quan, Tóm tắt lý thuyết cốt lõi, Ví dụ mẫu có lời giải chi tiết, Câu hỏi kiểm tra dạng trắc nghiệm/tự luận ngắn (graded), và thẻ học thông minh SRS.
2. **Đăng ký bài học vào Registry**:
   - Tích hợp 25 bài Vật lí 12 mới vào `PHYSICS_LESSONS` trong `lessons.ts`, nâng tổng số bài học Vật lí lên **85 bài**.
3. **Cập nhật `packages/core-grading`**:
   - Thêm các đơn vị vật lí nhiệt, điện từ, hạt nhân đặc thù bao gồm: `J/kg`, `kJ/kg`, `J/(kg.K)`, `J/kg.K`, `J/(kg*K)`, `J/kg*K` (Nhiệt dung riêng, nhiệt hoá hơi/nóng chảy riêng); `amu`, `eV`, `MeV` (Khối lượng/Năng lượng hạt nhân); `ngày^-1`, `ngày-1` (Hằng số phóng xạ).
   - Thêm đơn vị thể tích dạng chữ: `lít`, `lit`.
4. **Cập nhật mục tiêu**:
   - Chuyển trạng thái `M3/S3` thành `DONE`.
   - Chuyển trạng thái `M4` (Sinh học 10-12) thành `IN_PROGRESS`.

### Kiểm chứng

- **Build**: `npm run build:packages` hoàn tất không lỗi.
- **Typecheck & Lint & Format**: `npm run typecheck && npm run lint && npm run format:check` pass sạch sẽ.
- **Unit tests**: `npx vitest run packages/subject-physics packages/core-grading` vượt qua 100% test case (đáp án khai báo tự chấm chính xác).
