# Phase 44 — Architecture Governance

## Objective

Prevent architectural drift over the lifetime of the product.

## ADRs

At minimum: learner source of truth, agent authority, evidence, mastery, workflow, events, model routing, memory, voice and scaling.

## Steps

Require ADR for cross-cutting decisions; record context/options/decision/consequences/status; review exceptions; keep contracts/version policy current; run architecture checks in CI.

## Acceptance

Major architecture changes are reviewable and traceable; undocumented coupling is treated as technical debt with an owner.
