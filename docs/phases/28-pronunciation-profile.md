# Phase 28 — Pronunciation Profile

## Objective

Maintain longitudinal pronunciation strengths and recurring phoneme/prosody issues.

## Data

Per-learner phoneme scores, stress/rhythm/intonation, fluency, common errors, confidence, source/version.

## Steps

Normalize provider outputs; aggregate repeated observations; map errors to pronunciation knowledge/skills; generate targeted practice and SRS candidates; keep raw evidence for audit.

## Tests

Phoneme boundaries, sparse observations, conflicting scores, language-specific phonemes and provider version changes.

## Acceptance

Pronunciation can feed the same Evidence → Mastery → SRS loop as text skills.
