# Phase 34 — Experimentation OS

## Objective
Safely compare learning interventions.

## Steps
Define experiment/variant/cohort contracts; deterministic assignment; exposure logging; pre/post/delayed metrics; guardrails; stop criteria; privacy/consent. Examples: explicit vs self-correction, lesson sequencing, model routing.

## Acceptance
Experiments cannot alter authoritative learner state outside declared intervention policies and can be audited by version.
